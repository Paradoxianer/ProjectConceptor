◆ GetConfigMessage()

BMessage * ConfigManager::GetConfigMessage ( const char * name = NULL)

returns the Configuration for the given name, or the whole config if NULL. Passing a name returns a copy owned by the caller (delete it when done, and pass an edited copy to SetConfigMessage() to persist changes); passing NULL returns the live config object - do not delete it.
