◆ P_C_CONFIG_MACRO_SHORTCUTS_FIELD

const char* P_C_CONFIG_MACRO_SHORTCUTS_FIELD = "MacroShortcuts"

Field names for the app-wide MacroShortcuts list in ConfigManager (a flat repeating list like ShortCutFilter's own AddShortCutList() format: P_C_SHORTCUT_KEY_FIELD/P_C_SHORTCUT_MODIFIERS_FIELD/ P_C_MACRO_SHORTCUT_NAME_FIELD per entry, matched by index).

◆ P_C_CONFIG_SHORTCUTS_FIELD

const char* P_C_CONFIG_SHORTCUTS_FIELD = "Shortcuts"

Field name for the app-wide editor action shortcuts in ConfigManager (a BMessage keyed by action name, each entry a BMessage with P_C_SHORTCUT_KEY_FIELD/P_C_SHORTCUT_MODIFIERS_FIELD int32 fields), and the action names GraphEditor currently binds.

◆ P_C_CONFIG_WINDOW_FRAME_FIELD

const char* P_C_CONFIG_WINDOW_FRAME_FIELD = "WindowFrame"

Field names inside the app-wide remembered-window-frame ConfigManager entry: "frame" (BRect) is restored for new document windows and updated when a window closes; "remember" (bool, defaults to true - today's always-on behavior - when absent) gates both directions.

◆ P_C_DOC_FORMAT_VERSION_FIELD

const char* P_C_DOC_FORMAT_VERSION_FIELD = "pc:format_version"

Field name for the document format version written by PDocument::Archive() and checked by PDocument::Load(). Bumped whenever the on-disk shape of a document changes in a way older builds can't read (e.g. the move from pointer-identity to int32 ids in the Indexer).

◆ P_C_NODE_CONNECTION_ARROWS

const char* P_C_NODE_CONNECTION_ARROWS = "Connection::arrows"

int8 bitmask, which ends of a connection carry an arrow head: 1 = at the target, 2 = at the source, 3 = both, 0 = none. Missing on connections saved before this existed - ConnectionRenderer adds it with the target-only default, matching how they used to draw.
