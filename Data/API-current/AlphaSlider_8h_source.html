9 * ProjectConceptor additions:
10 * - the drag position is drawn as the same round selector knob
11 * BColorControl's own R/G/B ramps use - same constants, same two-
12 * stroke technique (see _DrawThumb() in the .cpp and
13 * BColorControl::_DrawSelectors() in
14 * ~/repos/haiku/src/kits/interface/ColorControl.cpp) - instead of the
15 * original ported code's plain white/black marker lines, so the alpha
16 * control's handle matches the ramps right above it in
17 * ColorPickerWindow rather than looking like a different control.
18 * (An earlier version of this tried BSlider's rectangular "block
19 * thumb" via be_control_look->DrawSliderThumb() instead - visually the
20 * wrong shape for this context, replaced.)
21 * - a small checkerboard-aware swatch "end cap" at the end of the
22 * gradient bar (see _EndCapRect()/_DrawEndCap() in the .cpp), showing
23 * the resulting color at the current alpha value - drawn with the same
24 * checkerboard style ColorSwatchView uses for the palette/history rows
25 * elsewhere in ColorPickerWindow, so this reads as the same "color
26 * swatch" visual language too.
