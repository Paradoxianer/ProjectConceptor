Detailed Description

PCommand's contract is that Do() followed by Undo() restores the exact prior state - this checks that holds for ChangeValue, without needing a running app (PCommand::Do/Undo only need doc->GetChangedNodes()/ GetSelected()/SetModified(), all safe on a headless PDocument).
